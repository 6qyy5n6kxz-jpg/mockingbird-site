# Private event menu: recipe costing

How the per-guest prices on the private event estimate page (`js/private-menu-pricing.js`) were set (November 2026).

## Method

- Each item uses a standard published home-style recipe scaled for a buffet, with a realistic buffet serving (sides about ½ cup, proteins about 5 oz cooked).
- **Price = ingredient cost per serving × 1.10 (waste) ÷ 0.30 (30% food cost)**, rounded up to the next $0.25.
- Minimum prices: sides $2.50, salads and appetizers $3.00, brunch items $2.50, mains $3.50. Labor and setup are why a cheap side still costs at least $2.50.
- Tax and the 18% service charge are added on top by the estimate page, as before.
- Not costed (prices unchanged): boards, stations and bars, soup, antipasto and flatbreads.
